# 8. Continuous Integration, Deployment, and Hosting

## 8.1 Continuous Integration and Deployment

**GitHub Actions** runs the group's CI/CD pipeline, satisfying the requirement
that the project make use of continuous integration and deployment for both
collaboration and deployment.

## 8.2 Hosting

- **Frontend** — hosted on Vercel
- **Backend** — hosted on Render or Railway

Both minimise the infrastructure work required of the group, with free tiers
suited to a student project.
